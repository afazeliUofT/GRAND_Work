## 1. Scope and method of this review

This is a proof review in the sense requested by the bundle: every theorem, lemma, proposition, and boundary convention in the manuscript and proof supplement was re-derived independently, and each obligation in `04_EXTERNAL_PROOF_REVIEW_CHECKLIST.md` is answered PASS or with the smallest counterexample / incorrect line / precise repair. Independence was enforced in two ways. First, every proof was reconstructed by hand from the stated model, not from the authors' proof text, and then compared line by line against the supplement. Second, every algebraic identity, coordinate convention, and finite-length constant was recomputed with symbolic computer algebra and exact rational (fraction) arithmetic — never floating point for any comparison that a theorem depends on — using code written for this review and independent of the authors' implementation. A reference decoder implementing Algorithm 1 exactly as printed (shell enumeration, canonical insertion generator, global seen-set, complete alignment-summed scoring, strict shell certificate) was written from the manuscript alone and cross-validated against brute-force exhaustive ML over random and exhaustive instance sets. The numerical evidence in the bundle was treated as supporting material only; no conclusion below depends on it.

The channel model under review, restated for the record: `X ∈ {0,1}^n`; independent substitutions `X̃_i = X_i ⊕ N_i`, `N_i ~ Bernoulli(p_s)`, `0 ≤ p_s < 1/2` (theorems use `0 < p_s < 1/2` where stated); exactly one coordinate `J`, uniform on `{1,…,n}`, is deleted; observation `Y ∈ {0,1}^m`, `m = n−1`; the code `C ⊆ {0,1}^n` is arbitrary, nonempty, uniformly used, and accessed only through a membership test; the alignment mismatch count is `d_j(x,y) = Σ_{i<j} 1{x_i≠y_i} + Σ_{i>j} 1{x_i≠y_{i−1}}`.

## 2. Item-by-item findings against `04_EXTERNAL_PROOF_REVIEW_CHECKLIST.md`

### Item 1 — Channel law with substitutions before deletion, deleted-coordinate substitution marginalized. **PASS.**
Conditioning on `J = j`, the survivor comparisons are `(x_i, y_i)` for `i < j` and `(x_i, y_{i−1})` for `i > j`; the deleted coordinate's noise variable `N_j` sums to one, so
`W(y|x) = (1/n) Σ_{j=1}^{n} p_s^{d_j}(1−p_s)^{m−d_j}`
is exact. Verified two independent ways with exact rationals: (a) full enumeration of all `2^n` noise vectors on **all** `n` coordinates (i.e., including the deleted coordinate's substitution, so the marginalization step itself is tested) times all `n` deletion positions, for every `(x, y)` pair at `n = 3, 4, 5` — the formula matched the brute-force law in every one of the `2^n · 2^{n−1}` cells at each `n`; (b) the delete-first / substitute-survivors ordering was enumerated separately and shown identical, confirming the order-equivalence remark. No discrepancy.

### Item 2 — Sliding mismatch recurrence under the manuscript's coordinate convention. **PASS.**
Algebraically, moving the hypothesized deletion from `j` to `j+1` removes the suffix comparison `(x_{j+1}, y_j)` and adds the prefix comparison `(x_j, y_j)`, giving exactly the printed `d_{j+1} = d_j − 1{x_{j+1}≠y_j} + 1{x_j≠y_j}`; the index `y_j` exists for all `j ≤ n−1 = m`, so the recurrence is well-formed over its whole range, and `d_1 = Σ_{i=2}^{n} 1{x_i ≠ y_{i−1}}` is the correct anchor. Verified on 3,000 random `(x, y)` pairs with `n` up to 64 against direct evaluation of the definition: exact agreement in all cases. The `O(n)` claim for all `n` alignment terms follows.

### Item 3 — Mismatch multiplicities and factorization in the strict reversal theorem, including `n = 4` and the equality boundary. **PASS.**
For `y = 0^{n−3}10`, `x_A = 0^{n−3}101`, `x_B = 0^n`, direct computation of the full alignment profile gives, for every `n` from 4 through 14 (checked exhaustively), `d_j(x_A, y) = 3` for `j ≤ n−3`, then `2, 1, 0` for `j = n−2, n−1, n` — i.e., multiplicities `1, 1, 1, n−3` at distances `0, 1, 2, 3` exactly as stated (at `n = 4` this is `1,1,1,1`), and `d_j(x_B, y) = 1` for all `j`. The factorization
`n(W(y|x_B) − W(y|x_A)) / (1−p_s)^{n−4} = (1−2p_s)(np_s − 1 − 2p_s²)`
was verified as a symbolic identity in the two variables `(n, p_s)` — the expanded difference `−1 + (n+2)p − (2n+2)p² + 4p³` matches the expanded product term-for-term — so the "if and only if" is exact, with the first factor strictly positive on `0 < p_s < 1/2`. The equality boundary was checked exactly: at the algebraic root `p_s* = (n − √(n²−8))/4` of `np_s = 1 + 2p_s²` (which lies in `(0, 1/2)` for every `n ≥ 4`; e.g., `1 − √2/2 ≈ 0.29289` at `n = 4`), symbolic evaluation gives `W(y|x_A) = W(y|x_B)` exactly — a genuine tie, consistent with the strict "if and only if". The best-history side, `M_y(x_A) = n^{−1}(1−p_s)^m > n^{−1}p_s(1−p_s)^{m−1} = M_y(x_B)`, is strict for all `0 < p_s < 1/2`, verified on a fine rational grid for `n = 4…10`. One contextual observation: at the campaign operating point `(n, p_s) = (32, 0.05)`, `np_s = 1.6 > 1.005`, so the reversal family is active in-regime, which is a satisfying alignment between the structural theorem and the empirical setting.

### Item 4 — The `n+1` one-insertion-sphere generator, labeled classical. **PASS.**
Exhaustively for all `z` with `m ≤ 10` and on random `z` up to `m = 14` (including `m = 0`): the set of all one-insertion supersequences of `z` has cardinality exactly `m + 2 = n + 1`; the canonical generator (insert `b` in the first gap and immediately after each symbol of `z` unequal to `b`, for `b ∈ {0,1}`) emits exactly this set with no duplicates. The counting argument in Lemma "One-insertion sphere" is correct: two insertion gaps of the same bit coincide iff every intervening symbol equals that bit, giving `1 + #{i : z_i ≠ b}` distinct outputs per bit, summing to `m + 2`; the two bit classes have Hamming weights `wt(z)` and `wt(z)+1` and are therefore disjoint. The result is correctly and repeatedly labeled classical (manuscript: "Its classical cardinality is `n+1`"; supplement Remark 6; novelty matrix: "Prior art; do not claim"), which is the right call — this is the binary single-insertion ball size known since the classical insertion/deletion literature.

### Item 5 — Discovery-shell characterization, both directions. **PASS.**
Forward: for any alignment `j`, deleting `x_j` yields `z` with `z = y ⊕ e`, `wt(e) = d_j(x,y)` (index bookkeeping re-derived and confirmed), and reinserting the bit value `x_j` at coordinate `j` reconstructs `x`; since the generator emits all of `I(z)`, `x` is emitted in shell `d_j` for every `j`, hence first appears no later than shell `h_y(x) = min_j d_j`. Converse: any emission of `x` in shell `s` comes with a witness pair (insertion coordinate `j`, error `e` of weight `s`), and deleting coordinate `j` from `x` returns `y ⊕ e`, so `d_j(x,y) = s` and `h_y(x) ≤ s`. Together: first shell `= h_y(x)` exactly, and "generated by end of shell `s` iff `h_y(x) ≤ s`". Verified exhaustively for `n = 4, 5, 6` over **every** observation `y` and **every** candidate `x`: the first shell in an instrumented run of the exact enumeration equals `min_j d_j` in all `2^m · 2^n` cells at each `n`, and coverage of all `2^n` words by shell `m` holds in every case (each `d_j` sums `m` indicators, so `h_y(x) ≤ m` always).

### Item 6 — Unseen after shell `s` implies every alignment distance at least `s+1`. **PASS.**
This is the contrapositive of the Item-5 equivalence: unseen after shell `s` ⇔ `h_y(x) > s` ⇔ `min_j d_j ≥ s+1` ⇔ every `d_j ≥ s+1`. Verified exhaustively alongside Item 5 in both directions for `n = 4, 5, 6`, all `y`, all `x`, all `s < m`. Consequently, since `t ↦ p_s^t(1−p_s)^{m−t}` is strictly decreasing for `p_s < 1/2`, every alignment term of an unseen word is at most `U_s = p_s^{s+1}(1−p_s)^{m−s−1}`, and the uniform average over `n` alignments is no larger. The exponent `m−s−1 ≥ 0` is well-defined precisely because the certificate is only invoked for `s < m`.

### Item 7 — Strict incumbent comparison is necessary for complete ML tie-set certification. **PASS** — and the necessity is here made constructive with an explicit witness.
Sufficiency of strictness is proved correctly in Theorem "Unseen-candidate certificate": incumbent `> U_s` excludes both an unseen maximizer and an unseen tie, and all discovered codewords are exactly scored, so the discovered tie set is the complete global one. The manuscript's converse assertion ("The strict inequality is required to certify the complete tie set") is asserted without a witness; this review verified it by constructing the smallest-style witness independently, which the authors may cite or reproduce:

> **Necessity witness.** Take `n = 5`, `m = 4`, `y = 0101`, `C = {x_1, x_2}` with `x_1 = 10100`, `x_2 = 00000`, and `p_s* = (5 − √17)/4 ≈ 0.21922` (equivalently `ρ* = p_s*/(1−p_s*) = (√17 − 3)/4`, the root in `(0,1)` of `2ρ³ + ρ² − 4ρ + 1 = 0`). The alignment profiles are `d(x_1, y) = (1,2,3,4,4)` so `h_y(x_1) = 1`, and `d(x_2, y) = (2,2,2,2,2)` so `h_y(x_2) = 2`. Exact symbolic evaluation gives `W(y|x_1) = W(y|x_2) = p_s*²(1−p_s*)² = U_1` **exactly**. Therefore, after completing shell `s = 1`, the incumbent `x_1` is discovered and completely scored at exactly `U_1`, while `x_2` is still unseen and ties exactly. A non-strict stopping rule (incumbent `≥ U_s`) halts here and returns the incomplete tie set `{x_1}`; the true ML tie set is `{x_1, x_2}`. Strictness is thus necessary for tie-set completeness, exactly as claimed. (The general structural fact used: a candidate has a constant alignment profile iff it is a constant word, and `x_2 = 0^n` against any `y` with `wt(y) = s+1` sits exactly on `U_s`; the companion `x_1` realizes the profile `(1,2,3,4,4)`, which is feasible because consecutive `d_j` differ by at most one, and the alternating `y` makes the required equality polynomial have a root in `(0,1)`.)

Note the correct residual guarantee under non-strict comparison, which the general certificate theorem in the companion proposal states properly: with `≥`, the returned incumbent is still *an* ML codeword; only completeness of the tie list fails. The Paper-I documents are consistent with this distinction.

### Item 8 — `p_s = 0` and `p_s = 1/2` boundary statements. **PASS.**
At `p_s = 0` (indicator convention `0^0 = 1`): a word has positive likelihood iff some alignment distance is zero iff it lies in shell 0 `= I(y)`; verified exhaustively for `n = 4, 5, 6` over all `y` and all `x` — the set `{W > 0}` equals `I(y)` in every case, exactly as the manuscript's remark states. At `p_s = 1/2`: `p^d(1−p)^{m−d} = 2^{−m}` independent of `d`, so `W(y|x) = 2^{−m}` for every word (verified exactly for `n = 4, 5`); the strict certificate can never fire, and only finite exhaustion at shell `m` remains — again exactly the manuscript's statement. Both boundary remarks are correct, and both boundary cases are properly excluded from the strict-decay theorems by the standing assumption `0 < p_s < 1/2` where those theorems need it.

### Item 9 — Definition and floor formula for `L_n(p_s)`, especially exact logarithmic boundaries. **PASS.**
With `ρ = p_s/(1−p_s) < 1`, `ρ^ℓ < 1/n ⇔ ℓ > log_{1/ρ} n`, and the least integer strictly exceeding a real `a ≥ 0` is `⌊a⌋ + 1` — including when `a` is an integer, which is exactly the exact-logarithm boundary case; the strict `<` in the definition pairs correctly with `⌊·⌋ + 1`. Verified with exact rational cross-multiplication (no logarithms, no floats) over 2,207 `(p_s, n)` pairs, including deliberately constructed exact boundaries `ρ = 1/2` (`p_s = 1/3`) with `n = 2^k` for `k = 1…11` and `ρ = 1/3` (`p_s = 1/4`) with `n = 3^k` for `k = 1…7`: the direct minimum and the floor formula agree everywhere, and at every exact boundary both correctly return `k + 1`, never `k`. The manuscript's specific values `L_16 = 1, L_24 = 2, L_32 = 2` at `p_s = 0.05` were reproduced exactly.

### Item 10 — Realization-dependent stopping ratio `n ρ^{L_n} < 1` and its indexing. **PASS.**
`T` is the substitution count on the `m` survivors; under the true deletion position `j_0`, `d_{j_0}(x_0, y) = T` exactly, so the transmitted word is discovered by the end of shell `T` (since `L_n ≥ 1`, it is present before the claimed stopping shell) and contributes the single-alignment lower bound `n^{−1} p_s^T (1−p_s)^{m−T}` to the incumbent. At `s = T + L_n − 1`,
`U_s / [n^{−1} p_s^T(1−p_s)^{m−T}] = n ρ^{L_n} < 1` **strictly**, by the strict `<` in the definition of `L_n` — so the strict certificate fires by the end of that shell, and `S ≤ min{m, T + L_n − 1}` with the `m` branch covering exhaustion. Verified exactly for a grid of rational `p_s` and all `n ≤ 300` that `nρ^{L_n} < 1` holds strictly and that `L_n` is minimal (`nρ^{L_n − 1} ≥ 1` whenever `L_n ≥ 2`). The indexing was additionally verified operationally: in 540 exact-arithmetic channel simulations of the printed Algorithm 1 (`n ∈ {5,6,7}`, `p_s ∈ {0.05, 0.3, 0.45}`, random codes of size 1–10, random transmissions), the realized stopping shell satisfied `S ≤ min{m, T + L_n − 1}` in every trial with zero violations. The monotonicity that makes "no later than" rigorous (incumbent non-decreasing, `U_s` strictly decreasing in `s`) holds. The bound uses only that the transmitted word is a codeword — it is code-independent as claimed.

### Item 11 — Deterministic, finite-confidence, and expected query bounds. **PASS.**
Deterministic: shells `0…S` contain `Vol(m, S) = Σ_{w≤min(m,S)} C(m,w)` error vectors, each contributing exactly `n+1` distinct supersequence emissions, so `Q_gen ≤ (n+1)Vol(m,S)`, `Q_mem ≤ Q_gen` (global seen-set only removes queries), `Q_score ≤ Q_mem` (only members are scored); the `2n·Vol(m,S)` history-pair count is likewise correct (`n` alignments × 2 bits per error vector). All three inequalities held in all 540 simulated trials and in 192 exhaustive-`y` cells. Finite-confidence: `T ~ Binomial(m, p_s)` exactly (the survivor set has size `m` for every deletion position), so `P[T ≤ τ_δ] ≥ 1−δ` transfers through the monotone map `T ↦ (n+1)Vol(m, min{m, T+L_n−1})` to the displayed cap; correct. Expected-value bound: direct conditioning on `T`; correct. **Table I was recomputed from scratch with exact binomial CDFs** (rational arithmetic): all six rows — `(L_n, τ_δ, cap)` = `(1,3,9792)`, `(1,4,32997)`, `(2,4,1113800)`, `(2,5,3637475)`, `(2,5,31107417)`, `(2,6,117883392)` — match the manuscript exactly, digit for digit. As an over-and-above cross-check, the "exact expected membership cap" values recorded in the frozen theory file (`902.1663`, `82611.1874`, `1723613.647` for `n = 16, 24, 32`) were reproduced independently to all displayed digits from the expectation formula.

### Item 12 — Hoeffding/Hamming-ball argument and every `o(1)` transition in the high-probability exponent. **PASS**, with one purely presentational note.
With `ε_n = √(c ln n / (2m))`, `exp(−2mε_n²) = n^{−c}` was verified as a symbolic identity, and the one-sided Hoeffding bound `P[T > m(p_s+ε_n)] ≤ P[T ≥ m(p_s+ε_n)] ≤ exp(−2mε_n²)` is applied correctly to the bounded i.i.d. sum `T`. On the complementary event, `S ≤ T + L_n − 1 ≤ m(p_s + ε_n) + O(log n)`, so `S/m ≤ p_s + o(1)` since `ε_n → 0` and `L_n = Θ(log n)` for fixed `p_s` (growth confirmed: `L_n = 1, 2, 3, 4` at `n = 10, 10², 10³, 10⁴` for `p_s = 0.05`). The Hamming-ball bound `Vol(m, s) ≤ 2^{m h₂(s/m)}` for `s ≤ m/2` was verified exactly for all `m ≤ 60`; continuity of `h₂` at `p_s < 1/2` gives `h₂(S/m) = h₂(p_s) + o(1)`; the polynomial factor `n+1` is `2^{o(n)}`; and `m h₂(·) = n(h₂(p_s)+o(1))` since `m = n−1`. Every `o(1)` transition is legitimate. The rate comparison `|C_n|/Q_score ≥ 2^{n(R−h₂(p_s)−o(1))}` follows on the same event because `Q_score ≥ 1` on every realization (the transmitted codeword is always discovered by shell `T ≤ m`). **Presentational note (no correctness impact):** the step "`S/m ≤ p_s + o(1) < 1/2` on the complementary event" holds for all `n ≥ n₀(p_s, c)`; for small `n` the ball bound's hypothesis `S ≤ m/2` need not hold, but the statement is asymptotic and any finite prefix is absorbed by the `o(1)` convention. Adding the explicit qualifier "for all sufficiently large `n`" (or `n ≥ n₀(p_s,c)`) would make the proof airtight to a finite-`n` reader. This is a wording edit only. One empirical consistency remark supporting the correct reading of the corollary: the measured `n = 32` median membership exponent (`≈ 0.310`) exceeds `h₂(0.05) ≈ 0.2864`, which is fully compatible with the theorem — the corollary is asymptotic, and the paper's own finite-`n` Table-I caps (exponent `≈ 0.54` at `n=32`) are the finite-length statement; the manuscript nowhere claims the asymptotic exponent at finite `n`.
