# Novelty positioning for Phase 2C

The paper must not claim the following generic ideas as new:

- summing probabilities of multiple paths leading to one candidate;
- threshold/top-k stopping in sorted streams;
- GRAND-style code-membership testing;
- binary one-insertion-sphere cardinality;
- exhaustive ML or generic branch-and-bound.

The defensible candidate contributions are narrower:

1. an explicit strict one-deletion-plus-BSC coding family in which best-history and aggregate-ML orderings reverse;
2. the exact shell-certified inverse-alignment decoder specialized to aggregate deletion likelihoods;
3. the realization-dependent stopping theorem and finite-length work caps;
4. the high-probability membership/query exponent for arbitrary membership-testable codes;
5. exact finite-length certification and evidence separating membership, scoring, generation, and wall-clock costs.

The included literature note is provisional. A final claim-by-claim primary-source review is required before submission.
