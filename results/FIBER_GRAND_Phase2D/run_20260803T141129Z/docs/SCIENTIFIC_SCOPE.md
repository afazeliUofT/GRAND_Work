# Frozen Phase-2D scientific scope

Phase 2D performs manuscript integration and claim auditing only. It does not generate new channel realizations or rerun Phase 2C.

The conference candidate is restricted to:

- arbitrary nonempty binary block codes accessed through membership tests;
- exactly one uniformly located deletion;
- independent hard-decision BSC substitutions with `0 <= p_s < 1/2`;
- exact aggregate ML and complete tie-set certification;
- the strict reversal family;
- the baseline shell-certified decoder;
- realization-dependent and high-probability query bounds;
- the frozen Phase-2C exact finite-length evidence.

Excluded: multiple deletions, insertions as a channel event, soft outputs, list decoding, code design, transducers, hardware, and the practical-acceleration claim for `U_AC`.
