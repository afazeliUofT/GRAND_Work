# Phase 2B result-manifest scope

`MANIFEST.sha256` is the package-generated scientific-output manifest created before wrapper metadata is appended. `COMMIT_READY_MANIFEST.sha256` is generated by the WSL wrapper after all result metadata and the GitHub review pointer exist. It covers every committed file in this result directory except itself and the uncommitted local return ZIP. The return ZIP's SHA-256 sidecar is covered.
