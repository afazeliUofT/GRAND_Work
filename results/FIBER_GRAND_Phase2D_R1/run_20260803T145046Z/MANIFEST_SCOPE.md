# Phase 2D-R1 commit-manifest scope

`SCIENTIFIC_OUTPUT_MANIFEST.sha256` covers the package-generated repair and review artifacts. `COMMIT_READY_MANIFEST.sha256` is generated by the WSL wrapper after all wrapper metadata, the Windows-copy record, and GitHub review pointer exist. It covers every committed file in this result directory except itself and the uncommitted local Phase-2D-R1 return ZIP.
