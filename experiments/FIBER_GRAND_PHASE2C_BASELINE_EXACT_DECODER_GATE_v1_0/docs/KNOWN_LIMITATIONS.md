# Known limitations

1. The channel is exactly one uniform deletion plus hard-decision substitutions; no insertion, multiple deletion, soft-information, or transducer claim is tested.
2. The high-probability theorem is a membership-oracle/query-complexity result. It is not a universal RAM, energy, or latency optimality theorem.
3. The exhaustive codeword-ML comparator is a clear exact baseline, not the strongest possible decoder for every structured code.
4. The branch-and-bound comparator is generic and generator-order dependent. Censored branch runs are not treated as exact comparisons.
5. The campaign uses three code families and one substitution probability. It is a bounded conference kill/GO gate, not a final broad journal campaign.
6. Extended Hamming and the tested CRC/random codes are not claimed to be optimal synchronization-error codes. Error-rate results therefore characterize these frozen codes, not the best achievable one-deletion performance.
7. The binary one-insertion-sphere cardinality is classical. Its use here is an implementation reduction, not an independent novelty claim.
8. The proof source has internal exact support but still requires independent human proof review and a refreshed external novelty audit.
9. The previously studied exact alignment-consistent `U_AC` certificate remains mathematically correct but is not reintroduced as a practical acceleration.
